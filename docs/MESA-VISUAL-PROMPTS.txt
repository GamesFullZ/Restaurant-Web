CÓMO USAR ESTE ARCHIVO
- Cada sección tiene un ID (IMG-001 … IMG-059) con dos prompts que representan LA MISMA sección:
    PROMPT A — VISUAL DESIGN: referencia high-fidelity (cómo se ve).
    PROMPT B — BLUEPRINT / PLANO: plano arquitectónico aplicado a UI (cómo está construido).
- Los prompts están escritos en inglés (mejor rendimiento en la mayoría de IAs de imagen). Todo texto que debe aparecer DENTRO de la interfaz está en español entre comillas y debe reproducirse tal cual.
- Cada prompt es autocontenido: se puede copiar y pegar sin depender de otros.
- Formatos sugeridos: desktop 16:10 (p. ej. 1600×1000) · composiciones desktop+mobile 16:9 · mobile 9:19.5 · blueprints 16:10 horizontal (formato lámina) · fotografía gastronómica 4:5 vertical.
- Al final: FOOD PHOTOGRAPHY PROMPTS (FP-01 … FP-25), uno por cada platillo del menú inicial (10-data-specification §7.5).

NOTA DE DIRECCIÓN DE ARTE (ajuste respecto a 16-design-direction §7)
La documentación reinterpretaba el papel picado como "retículas de perforaciones". Por indicación de dirección de arte, el papel picado queda excluido por completo (ni literal ni como banderines). Esa capa gráfica se traduce aquí a una RETÍCULA DE CÍRCULOS Y PUNTOS derivada de la idea rectora "la mesa vista desde arriba" (platos, tortillas, sillas como puntos). Grecas, talavera modular, maíz y cantera se mantienen como abstracciones sutiles. Recomendación: reflejar este ajuste en 16-design-direction.md §7 y 17-motion-interaction.md §4–§6 en la próxima revisión de documentación.

01 — GLOBAL VISUAL DIRECTION
============================================================

Estos bloques ya están integrados dentro de cada prompt; se incluyen aquí como referencia y para ajustar la identidad en un solo lugar si se desea.

[BLOQUE DE ESTILO A — VISUAL DESIGN]
High-fidelity web UI design for MESA, a fictional contemporary Mexican restaurant in Monterrey. Premium editorial art direction: elegant, sophisticated, bold, creative, memorable; minimalist with generous negative space; one protagonist idea per screen. Guiding visual idea: "the table seen from above" — flat surfaces, circles (plates, tortillas), rectangles (tables), dots (chairs), shared rhythm. Palette: warm bone off-white "Nixtamal" #F4EFE6 as base; warm near-black "Obsidiana" #161412 for text and dark editorial sections; deep chile red-orange #C4432A as the only strong accent (under 10% of any screen, used for primary CTAs and selection); deep nopal green #2E4A3B for contrast sections and "available/confirmed"; sand-rose "Cantera" #D8C3AE for surfaces and cards; ochre "Maíz" #DDA43A only for tiny highlights such as the "Nuevo" badge. Typography: oversized high-contrast contemporary serif for display headlines (can span full width in 3 lines), clean neutral grotesk sans for UI and body (16 px+), monospaced accent for reservation codes and eyebrows, tabular numerals for prices and times. Subtle, reinterpreted Mexican graphic language: hairline stepped "greca" lines, concentric maize-grain circles, two-tone four-quadrant modular tile geometry (abstracted talavera), soft mineral cantera stone texture, a faint warm radial "comal" glow. UI details: 1 px hairline dividers, softly rounded UI components (8–12 px radius), square-cut editorial image crops, high contrast text (WCAG AA), visible focus rings. All interface copy in Spanish exactly as quoted. Crisp, realistic, pixel-sharp screen design presented flat on a neutral background (no device frame unless stated).

[BLOQUE DE ESTILO B — BLUEPRINT / PLANO]
Architectural blueprint drawing of a web interface, treating the screen as a building floor plan. Cyanotype blueprint paper, deep blue #1E3A5C with subtle paper grain and faint fold marks; crisp white and pale cyan technical linework at 0.5–1 pt; dashed vertical column grid overlay with column numbers; dimension lines with arrowheads and measurements in px and percentages; numbered circular callouts with leader lines; different hatch patterns per zone type (content, interactive, media/3D, decorative/motion layer); dotted outlines for interactive hit areas; uppercase technical lettering in Spanish; section-cut markers and elevation notes for layer depth (z-index labels such as "Z0 FONDO / Z1 GRÁFICO / Z2 CONTENIDO / Z3 NAV"); motion shown as "ESTADO A → TRANSICIÓN → ESTADO B" with arrows, timing (ms) and easing notes; a legend box (solid = component boundary, dashed = grid, dotted = interactive area, diagonal hatch = motion layer, cross hatch = media/3D); a title block in the bottom-right corner reading "MESA · IMG-0xx · [SECCIÓN] · ESC 1:1 · HOJA xx/59". It must look like a professional architectural drawing set applied to UI — precise, annotated, structural — never a generic grey-box wireframe.

DIRECCIÓN COMÚN DE LA SERIE (ya incluida en cada prompt)
- Fotorrealismo, fotografía gastronómica profesional y editorial.
- Formato maestro vertical 4:5 (≥ 1600 px de alto); de él se derivan recortes 1:1 y 16:9 para el detalle.
- Luz natural lateral desde la IZQUIERDA en toda la serie; sombras suaves hacia la derecha.
- Fondo neutro cálido (tonos Nixtamal / Cantera), superficie de piedra clara o lino natural.
- Vajilla de cerámica artesanal lisa en tres acabados: arena (cantera), hueso (bone) o negro mate.
- Encuadre: cenital para platos y tostadas; tres cuartos para tacos, postres y bebidas. El platillo ocupa 40–55 % del cuadro.

- La descripción visual se basa en la descripción oficial del platillo. No se muestran ingredientes como lista en la interfaz (BR-043); aquí solo guían la imagen.
- Control de calidad: generar la serie completa, montar una hoja de contacto con las 25 y verificar coherencia (temperatura de color, dirección de luz, superficie, escala) antes de integrarlas.
